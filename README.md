# Bogotá Road Safety API

A **FastAPI** + **pandas** REST API to explore and analyze road incidents in Bogotá by locality, time of day, vehicle type and severity.

> The included dataset (`data/incidents.csv`) is **synthetic**, generated by `scripts/generate_sample_data.py` with realistic patterns (rush-hour peaks, fewer incidents on weekends, more in larger localities). You can replace it with an official open dataset that has the same columns.

## Features

- Paginated incident listing with filters (locality, severity, vehicle type, year)
- Summary stats: totals, breakdown by severity, fatality rate, busiest hour
- Group-by analytics: by locality, severity, vehicle type, hour, weekday or month
- Input validation with Pydantic and enums (invalid values return `422`)
- Interactive docs at `/docs` (Swagger UI)
- Tests with pytest using dependency overrides (no file I/O in tests)

## Tech stack

Python 3.11+ · FastAPI · pandas · NumPy · Pydantic · pytest

## Getting started

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python scripts/generate_sample_data.py   # (re)creates data/incidents.csv
uvicorn app.main:app --reload            # http://localhost:8000/docs
pytest
```

## Endpoints

| Method | Endpoint                 | Description                                       |
|--------|--------------------------|---------------------------------------------------|
| GET    | `/health`                | Health check                                      |
| GET    | `/localities`            | List of localities in the dataset                 |
| GET    | `/incidents`             | Paginated list. Filters + `limit`, `offset`       |
| GET    | `/incidents/{id}`        | One incident                                      |
| GET    | `/stats/summary`         | Totals, severity breakdown, fatality rate         |
| GET    | `/stats/group?by=hour`   | Counts grouped by `locality`, `severity`, `vehicle_type`, `hour`, `weekday` or `month` |

All list and stats endpoints accept the filters `locality`, `severity`, `vehicle_type` and `year`.

### Examples

```bash
# Fatal incidents in Kennedy during 2024
curl "http://localhost:8000/incidents?locality=Kennedy&severity=fatal&year=2024"

# Which hours have the most motorcycle incidents?
curl "http://localhost:8000/stats/group?by=hour&vehicle_type=motorcycle"
```
